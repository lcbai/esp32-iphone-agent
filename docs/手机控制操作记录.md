# ESP32 控制 iPhone 操作记录

记录日期：2026-11-21。以下是本次在实体设备上验证过的方法，坐标和速度需要根据设备、屏幕尺寸及校准结果调整。

## 连接与准备

- ESP32-S3 通过 USB 连接 iPhone，手机开启「设置 → 辅助功能 → 触控 → 辅助触控」，并保持解锁。
- ESP32 与 iPhone 连接同一个 2.4 GHz Wi-Fi。iPhone 控制中心的「屏幕镜像」选择 ESP32 Agent。
- Mac 上运行 `esp32agent device info`，确认 `ap` 为 `streaming`、`usb` 为 `ok`；`esp32agent screenshot --output /tmp/phone.png` 获取画面。电脑可以通过 Wi-Fi 或蓝牙向板子发送控制指令。
- 本次将辅助触控的追踪灵敏度调到最低，取得较稳定的校准结果。更改灵敏度或设备后应重新校准。

## 当前使用的程序与校准

本次测试在本地修改了 `cli/internal/pointer/pointer.go`，允许修正较大的固定指针偏移。源码和对应测试尚未推送或安装到全局命令。测试程序由以下命令构建：

```sh
cd cli
go build -o /tmp/esp32agent-offset ./cmd/esp32agent
/tmp/esp32agent-offset calibrate
```

本机一次校准自检误差约为屏幕尺寸的 1.8%，随后已成功打开抖音、切换视频和打开评论区。校准可能因指针不可见、镜像延迟或连接异常失败；命令显示成功也应检查返回的 `error`。`/tmp` 文件可能在系统清理后消失，需要重新构建。切换到原版 `esp32agent` 可能重启后台服务并使用原版逻辑；应统一使用同一个程序。

## 已验证操作

坐标基于本次截图的 720 × 1560 像素；实际截图尺寸由 `screenshot` 返回，不应把这些坐标用于其他尺寸的手机。

```sh
# 打开抖音：主屏幕上图标中心位置（仅适用于本次布局）
/tmp/esp32agent-offset io tap 110,1110

# 在抖音推荐页切换下一个视频
/tmp/esp32agent-offset io swipe 350,1050,350,500
```

操作后等待画面稳定并重新截图，以视频作者或内容确认是否切换。点击评论、AI 解析和关闭按钮时，以当前截图确定按钮中心；不要盲目复用位置。

## 随机偏移与弯曲轨迹

用户希望操作位置加入随机偏移，范围为屏幕宽高各 ±5%。点击小按钮时将偏移限制在按钮内部。滑动时起点和终点采用相同偏移，并避开屏幕底部的系统手势区域。

本次成功切换视频时，先点击视频区域定位，再按住鼠标，分三段移动并释放，轨迹具有轻微弯曲。以下为当次使用的相对移动量，不保证适用于其他灵敏度：

```sh
/tmp/esp32agent-offset io tap X,Y
/tmp/esp32agent-offset device send press
/tmp/esp32agent-offset device send move 12 -110 30
/tmp/esp32agent-offset device send move -8 -160 30
/tmp/esp32agent-offset device send move -10 -130 30
/tmp/esp32agent-offset device send release
```

定位时的 `tap` 本身会点击视频，可能暂停或恢复播放；不是纯粹移动指针。若按住后中途失败，应尽快单独发送 `device send release`，避免按钮保持按下。滚轮和此前多次未校准的上划未能稳定切换，不能以命令返回成功代替实际画面验证。
